# minimal

scenaremo の最小構成の例。

| ファイル | 誰が所有するか |
|---|---|
| `script.yaml` | **あなた**。人間が書く唯一の入力 |
| `assets/` | **あなた**。台本から参照する画像（ここに置いてあるのはプレースホルダ） |
| `props.json` | **CLI**。手で編集しない（→ README「設計方針 1」） |

## props.json について

これは **CLI と Remotion の契約が実際にどういう JSON になるのかを示す見本**です。
renderer 側（issue #8 / #9）が VOICEVOX を起動せずに開発を始められるように置いてあります。

実際の build では動画ディレクトリの `.scenaremo/props.json` へ出力されます。
ここにあるのは `internal/props` のテストが `script.yaml` から生成したもので、
台本やスキーマを直したら作り直してください。

```bash
go test ./internal/props -update
```

見本として注意しておくこと:

- **音声の長さは実際に合成した値ではありません。** サンプルとして固定した値です
  （実測に頼るとエンジンのバージョンが変わるたびにテストが落ちるため）
- `audio` が指す wav はこのリポジトリに含まれません。`scenaremo build` が作ります。
  ファイル名は合成パラメータのハッシュなので、実物も同じ名前になります
- パスはすべて**動画ディレクトリからの相対**で、区切りは `/` です
